# Aide - file_tree_json

## Usage

file_tree_json [OPTIONS] [PATH] [--output FILE]

## Options

| Option | Description |
|--------|-------------|
| `--flat`, `-f` | Sortie sous forme de tableau JSON à plat |
| `--tree`, `-t` | Sortie sous forme d'arborescence JSON imbriquée (par défaut) |
| `--output, -o FILE` | Écrire la sortie dans FILE au lieu de stdout |
| `--help`, `-h` | Affiche ce message d'aide |

## Arguments

| Argument | Description |
|----------|-------------|
| `PATH` | Chemin du répertoire à analyser (par défaut : répertoire courant) |
